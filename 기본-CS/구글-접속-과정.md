# https://www.google.com 접속 시 일어나는 과정

## Q. https://www.google.com 접속 시 일어나는 과정은 무엇인가요?

### 답변
브라우저는 입력된 URL을 파싱해 프로토콜, 도메인, 경로를 분리하고, DNS Lookup을 통해 도메인에 해당하는 IP 주소를 조회합니다.

IP 주소를 얻으면 TCP 3-way handshake로 서버와 연결을 맺고, HTTPS이므로 TLS 핸드셰이크를 통해 서버 인증서를 검증하고 암호화 키를 교환합니다. 연결이 완료되면 브라우저가 HTTP 요청을 보내고, 서버는 HTML, CSS, JavaScript 등의 응답을 반환합니다.

마지막으로 브라우저는 HTML과 CSS를 파싱해 DOM과 CSSOM을 만들고, 렌더 트리 생성, 레이아웃, 페인트 과정을 거쳐 화면에 렌더링합니다. DNS Lookup 시에는 브라우저 캐시, OS 캐시, hosts 파일을 먼저 확인하고 없으면 DNS 서버에 조회합니다.

### 꼬리질문
- DNS Lookup은 어떤 순서로 진행되나요?
- HTTPS에서 TLS 핸드셰이크는 왜 필요한가요?
- TCP 3-way handshake란 무엇인가요?
- 브라우저 렌더링 과정은 어떻게 진행되나요?
