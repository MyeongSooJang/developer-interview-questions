# Factory

## Q. 팩토리 패턴이란 무엇인가요?

### 답변
팩토리 패턴은 객체 생성 책임을 클라이언트로부터 분리해, 클라이언트가 구체 클래스에 직접 의존하지 않게 하는 디자인 패턴입니다.

클라이언트가 `new 구체클래스()`로 직접 생성하면 구체 타입에 강하게 결합되어, 구현이 바뀔 때마다 클라이언트 코드도 수정해야 합니다. 팩토리를 통해 인터페이스 타입으로 받으면 OCP를 만족하고 변경 범위를 팩토리 내부로 한정할 수 있습니다.

실무에서는 Spring이 이 원리를 적극 활용합니다. Bean을 인터페이스로 주입받으면 구체 구현체를 교체해도 클라이언트 코드를 수정할 필요가 없어, 팩토리 패턴과 DI가 결합된 형태라고 볼 수 있습니다.
