# OSI 7계층

## Q. OSI 7계층이란 무엇인가요?

### 답변
OSI 7계층은 ISO에서 정의한 네트워크 통신 참조 모델로, 데이터가 송신자에서 수신자까지 전달되는 과정을 7개의 역할로 분리한 것입니다.

계층을 나누는 이유는, 문제가 생겼을 때 어느 계층에서 발생한 것인지 파악하기 쉽고, 각 계층의 프로토콜과 장비를 독립적으로 이해하고 교체할 수 있기 때문입니다. 예를 들어 케이블 문제면 물리 계층, TCP 연결 실패면 전송 계층, API 응답 오류면 응용 계층 문제로 접근할 수 있습니다.

실무에서는 OSI 모델보다 실제 구현에 맞는 TCP/IP 4계층이 주로 사용됩니다. HTTP는 응용 계층, TCP/UDP는 전송 계층, IP는 네트워크 계층에 속하며, 이 계층 구조를 이해하면 네트워크 트러블슈팅 시 원인 파악이 빨라집니다.

| 계층 | 이름 | 역할 | 대표 예시 |
|------|------|------|-----------|
| 7 | 응용 | 사용자가 접근하는 네트워크 서비스 | HTTP, HTTPS, FTP, DNS |
| 6 | 표현 | 데이터 형식 변환, 압축, 암호화 | SSL/TLS, JPEG |
| 5 | 세션 | 애플리케이션 간 세션 생성·유지·종료 | Session, Socket |
| 4 | 전송 | 종단 간 데이터 전송, 신뢰성 제어 | TCP, UDP |
| 3 | 네트워크 | IP 기반 경로 선택(라우팅) | IP, ICMP, Router |
| 2 | 데이터링크 | 인접 노드 간 프레임 전달 (MAC) | Ethernet, Switch |
| 1 | 물리 | 전기·물리적 신호 전송 | Cable, Hub |
