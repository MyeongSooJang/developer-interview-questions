# 트랜잭션

## Q. 트랜잭션이란 무엇인가요?

### 답변
트랜잭션은 여러 DB 작업을 하나의 논리 단위로 묶어, 전부 성공하거나 전부 실패하게 보장하는 메커니즘입니다.

이게 필요한 이유는, 예를 들어 계좌 이체처럼 출금과 입금이 분리돼 있을 때 중간에 오류가 나면 돈이 증발하는 문제가 생기기 때문입니다. 트랜잭션은 이를 rollback으로 막아주고, 모든 작업이 완료됐을 때만 commit해 데이터 정합성을 보장합니다.

실무에서는 Spring의 `@Transactional`로 메서드 단위 경계를 설정하고, ACID 특성 중 격리 수준을 상황에 맞게 조정해서 사용합니다.

### 꼬리질문
- ACID란 무엇인가요?
- commit과 rollback은 무엇인가요?
- Spring에서 트랜잭션은 어떻게 사용하나요?
- 트랜잭션 격리 수준에는 어떤 것들이 있나요?
- 격리 수준별로 발생할 수 있는 문제(Dirty Read, Non-Repeatable Read, Phantom Read)는 무엇인가요?
