# JVM

## Q. JVM이란 무엇인가요?

### 답변
JVM은 자바 바이트코드를 각 운영체제에 맞게 실행해주는 가상 머신입니다.
자바 코드는 컴파일하면 .class 바이트코드가 되고, JVM이 이를 JIT 컴파일러로 실행합니다.
이 구조 덕분에 Write Once, Run Anywhere가 가능해 OS에 종속되지 않고 개발할 수 있습니다.

또한 JVM은 GC로 메모리를 자동 관리하기 때문에 C/C++처럼 직접 메모리를 해제하지 않아도 됩니다.
다만 GC가 동작할 때 Stop-the-World가 발생할 수 있어, 레이턴시가 중요한 서비스에서는 GC 튜닝이 필요하기도 합니다.

## Q. JDK, JRE, JVM의 차이는 무엇인가요?

### 답변
JVM은 바이트코드를 실행하는 가상 머신이고, JRE는 JVM에 실행에 필요한 라이브러리를 포함한 실행 환경입니다.
JDK는 JRE에 컴파일러(javac)와 개발 도구를 추가한 개발 키트로, 개발 시에는 JDK가 필요합니다.

---

## Q. JVM의 메모리 구조는 어떻게 나뉘나요?

### 답변
Heap은 객체가 저장되는 영역으로 GC의 대상이 되고, Stack은 메서드 호출마다 생성되는 스택 프레임을 저장합니다.
Method Area(Metaspace)는 클래스 정보, 상수, 정적 변수를 저장합니다.

---

## Q. Java 프로그램은 어떤 순서로 실행되나요?

### 답변
.java 파일을 javac로 컴파일하면 .class 바이트코드가 생성됩니다.
JVM의 Class Loader가 이를 메모리에 로드하고, Execution Engine이 JIT 컴파일러로 기계어로 변환해 실행합니다.
