# Wrapper Class, Boxing/Unboxing

## Q. Wrapper Class란 무엇이며, Boxing과 Unboxing은 무엇인지 설명해주세요.

### 답변
Wrapper Class는 int, boolean 같은 원시 타입을 객체처럼 다루기 위해 감싸는 클래스로, Integer, Boolean처럼 원시 타입마다 대응하는 클래스가 존재합니다.
이때 원시 타입을 래퍼 객체로 변환하는 것을 박싱(Boxing), 반대로 래퍼 객체를 원시 타입으로 꺼내는 것을 언박싱(Unboxing)이라 부릅니다.

원시 타입은 객체가 아니기 때문에 제네릭 컬렉션처럼 객체만 담을 수 있는 곳에는 그대로 사용할 수 없고, 이때 래퍼 클래스로 감싸야 저장이 가능합니다.
자바 5부터는 컴파일러가 원시 타입과 래퍼 타입 사이의 박싱·언박싱을 자동으로 처리해주는데, 이를 오토박싱과 오토언박싱이라 합니다.

`List<Integer>`처럼 컬렉션에 값을 담을 때가 오토박싱이 자주 쓰이는 대표적인 경우입니다.
다만 오토박싱은 코드에 드러나지 않게 객체를 생성하기 때문에, 반복문 안에서 많이 발생하면 불필요한 객체 생성으로 성능이 저하될 수 있습니다.

### 꼬리질문

**Q. Integer 같은 래퍼 클래스는 오토박싱할 때 매번 새로운 객체를 생성하나요?**

A. 아니요, Java는 -128부터 127까지의 값은 미리 캐싱해두기 때문에 이 범위 안에서는 같은 객체를 재사용하고, 범위를 벗어나면 새로운 객체를 생성합니다.
