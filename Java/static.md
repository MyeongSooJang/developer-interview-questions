# static 키워드

## Q. static 키워드에 대해 설명해주세요.

### 답변
static은 인스턴스가 아닌 클래스 자체에 소속되는 필드나 메서드를 선언할 때 사용하는 키워드입니다.
static 멤버는 객체를 생성하지 않아도 클래스 이름으로 바로 접근할 수 있고, 해당 클래스의 모든 인스턴스가 하나의 메모리 공간을 공유합니다.

이는 클래스가 처음 사용될 때 클래스 로더가 클래스를 메서드 영역에 올리면서, 이 초기화 과정에서 static 필드의 초기화 코드와 static 블록을 딱 한 번만 실행하기 때문입니다.
반면 인스턴스 필드는 new로 객체를 생성할 때마다 힙 영역에 각각 따로 할당되기 때문에, 여러 인스턴스가 값을 공유하려면 static이 필요합니다.

대표적으로 상수(static final)나 인스턴스 상태에 의존하지 않는 유틸리티 메서드에 static을 사용합니다.
다만 static 필드는 클래스가 로딩된 시점부터 프로그램이 종료될 때까지 계속 메모리에 남아있고 여러 스레드가 동시에 접근할 수 있어서, 값이 바뀌는 용도로 사용하면 동시성 이슈가 발생할 수 있습니다.
