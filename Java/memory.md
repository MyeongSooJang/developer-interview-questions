# 자바 메모리 영역

## Q. 자바의 메모리 영역에는 뭐가 있는지 설명해주세요.

### 답변
자바의 메모리 영역은 JVM이 프로그램 실행 시 사용하는 Runtime Data Area로, 크게 5가지 영역으로 나뉩니다.

Method 영역은 모든 스레드가 공유하며 클래스, 인터페이스, static 변수 등의 바이트코드를 보관합니다.
Heap 영역은 new 키워드로 생성된 객체와 배열이 저장되는 곳으로, GC가 참조가 끊긴 객체를 이 영역에서 제거합니다.
Stack 영역은 스레드마다 독립적으로 존재하며, 메서드 호출 시 스택 프레임이 생성되어 지역변수와 매개변수가 저장되고 메서드 종료 시 프레임이 삭제됩니다.
PC Register는 스레드마다 존재하며 현재 실행 중인 명령어의 주소를 저장합니다.
Native Method Stack은 Java 외의 언어로 작성된 네이티브 코드 실행 시 사용되는 영역입니다.

### 꼬리질문
- Method 영역과 Heap 영역의 차이는 무엇인가요?
- 어떤 메모리 영역이 스레드 간에 공유되나요?
- 각 메모리 영역은 언제 할당되나요?

---

## Q. 어떤 메모리 영역이 스레드 간에 공유되나요?

### 답변
Method 영역과 Heap 영역은 모든 스레드가 공유하기 때문에 동시성 이슈가 발생할 수 있습니다.
반면 Stack, PC Register, Native Method Stack은 스레드마다 독립적으로 존재합니다.
이 때문에 멀티스레드 환경에서는 Heap에 저장된 객체에 대한 동기화 처리가 필요합니다.

---

## Q. 각 메모리 영역은 언제 할당되나요?

### 답변
Method 영역은 JVM이 시작될 때 클래스로더가 클래스를 로드하면서 할당됩니다.
Heap 영역은 new 키워드로 인스턴스가 생성될 때 할당됩니다.
Stack 영역은 메서드가 호출될 때 스택 프레임이 생성되며 할당되고, PC Register와 Native Method Stack은 스레드가 생성될 때 함께 할당됩니다.
