# 인터페이스와 추상 클래스

## Q. 인터페이스와 추상 클래스의 차이점에 대해 설명해주세요.

### 답변
추상 클래스는 공통 기능을 물려주기 위한 상위 클래스이고, 인터페이스는 특정 기능의 구현을 강제하는 계약입니다.

추상 클래스는 일반 메서드와 abstract 메서드를 함께 가질 수 있고, `extends`로 단일 상속만 가능합니다.
반면 인터페이스는 모든 메서드가 abstract이며, `implements`로 여러 개를 동시에 구현할 수 있습니다.

따라서 공통 속성을 공유하는 클래스들을 묶을 때는 추상 클래스를, 서로 다른 클래스에 동일한 기능을 강제할 때는 인터페이스를 사용합니다.

### 꼬리질문
- Java 8에서 인터페이스에 추가된 것은 무엇인가요?
- 추상 클래스 대신 인터페이스를 써야 하는 경우는 언제인가요?
- 인터페이스끼리 다중 구현 시 같은 이름의 default 메서드가 있으면 어떻게 되나요?

---

## Q. Java 8에서 인터페이스에 추가된 것은 무엇인가요?

### 답변
Java 8부터 인터페이스에 `default` 메서드와 `static` 메서드가 추가되었습니다.
`default` 메서드는 인터페이스에 구현부를 가질 수 있어, 기존 구현 클래스를 수정하지 않고도 인터페이스에 새로운 기능을 추가할 수 있게 됩니다.
이로 인해 추상 클래스와의 경계가 좁아졌지만, 다중 구현 가능 여부와 IS-A/CAN-DO 목적의 차이는 여전히 유효합니다.

---

## Q. 추상 클래스 대신 인터페이스를 써야 하는 경우는 언제인가요?

### 답변
서로 관련 없는 클래스들에 동일한 기능을 강제해야 할 때 인터페이스를 사용합니다.
예를 들어 `Bird`와 `Airplane`은 전혀 다른 개념이지만, 둘 다 `Flyable` 인터페이스를 구현함으로써 날 수 있다는 공통 계약을 가질 수 있습니다.
또한 다중 구현이 필요한 경우, 추상 클래스는 단일 상속만 가능하므로 인터페이스를 사용해야 합니다.
