# 불변 객체

## Q. 불변 객체란 무엇인지 설명해주세요.

### 답변
불변 객체란 한번 생성되면 내부 상태가 변하지 않는 객체로, Java의 `String`이 대표적인 예입니다.

`String`은 값을 변경하면 기존 객체를 수정하는 것이 아니라 새로운 객체를 생성하며, 이 때문에 String Constant Pool을 통해 동일한 값을 재사용할 수 있습니다.

불변 객체는 값이 절대 바뀌지 않기 때문에 여러 스레드가 동시에 접근해도 동기화 이슈가 발생하지 않고, 객체의 상태를 예측하기 쉬워 유지보수에도 유리합니다.

### 꼬리질문
- 불변 객체를 직접 만들려면 어떻게 해야 하나요?
- String이 불변 객체인데 왜 `+` 연산이 가능한가요?
- 불변 객체의 단점은 무엇인가요?
- 불변 객체의 또 다른 장점이 있나요?

---

## Q. 불변 객체를 직접 만들려면 어떻게 해야 하나요?

### 답변
클래스를 `final`로 선언해 상속을 막고, 모든 필드를 `private final`로 선언합니다.
`setter`를 제공하지 않고 생성자에서만 값을 초기화하면 외부에서 값을 변경할 수 없게 됩니다.
필드에 참조 타입이 있다면 방어적 복사를 통해 원본 객체가 변경되지 않도록 해야 합니다.

---

## Q. 불변 객체의 또 다른 장점이 있나요?

### 답변
실패 원자성을 보장할 수 있습니다.
불변 객체는 초기화가 완료되면 어떤 예외가 발생해도 객체가 이전 상태를 그대로 유지합니다.
이 때문에 메서드 실행 중 예외가 발생해도 객체가 망가지지 않아 안정적인 코드를 작성할 수 있습니다.

---

## Q. 불변 객체의 단점은 무엇인가요?

### 답변
값을 변경할 때마다 새로운 객체를 생성하기 때문에 메모리 사용량이 늘어날 수 있습니다.
예를 들어 `String`을 반복문에서 `+` 연산하면 매번 새 객체가 생성되어 성능 저하가 발생합니다.
이런 경우 `StringBuilder`처럼 가변 객체를 사용하는 것이 적합합니다.
